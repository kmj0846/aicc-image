# 거실 무드 스튜디오

시공 없이 소품·조명·배치만으로 거실 분위기를 바꾸는 방법을 제안하는 웹 프로토타입입니다. claude.ai Artifact로 배포되며, 페이지 안에서 Claude(`sample` capability)를 불러 사진을 분석합니다.

## 기능

- **분위기 제안**: 거실 사진(최대 6장)을 올리고 분위기·예산·조건을 고르면 빼기 / 더하기 / 옮기기 제안, 조명 팁, 배치 평면도(지금 ↔ 제안 후)를 보여 줍니다.
- **변경 후 미리보기**: 사진에서 뺄 물건을 주변 질감으로 지우고, 러그·화분·쿠션·액자 같은 소품을 원근에 맞춰 그리고, 전구색 조명을 입혀 전후 비교 슬라이더로 보여 줍니다. 위치와 색감을 보여 주는 간이 합성입니다.
- **실사 렌더 프롬프트**: 사진처럼 자연스러운 결과가 필요하면, 분석 결과에 포함된 영어 프롬프트를 이 저장소의 `aicc-image` 스킬에 사진과 함께 넘기면 됩니다.
- **소품 미리보기**: 사려는 소품 사진을 올리면 배경을 지우고 거실 사진 위에 끌어다 놓을 수 있습니다. Claude가 알맞은 자리를 찾아 주고, 어울리는지 점수와 이유를 알려 줍니다.

## 빌드

`index.html`은 예시 데이터 없이도 동작합니다. 예시 사진과 미리 만든 분석 결과를 넣은 배포본을 만들려면:

```bash
python3 build_sample.py out.html photo1.jpg photo2.jpg ... --analysis sample_analysis.json
```

`sample_analysis.json`의 좌표는 가로 사진 2000×1500, 세로 사진 1500×2000 기준 픽셀값이며 빌드할 때 비율로 바뀝니다. 개인 사진과 분석 파일은 저장소에 커밋하지 않습니다.
